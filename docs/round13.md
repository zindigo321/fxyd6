## Interfaces and evidence

* `Archive`: root ZIP and MANIFEST identities, safe selective extraction, read-only vendor consumption, actual read list, streaming before/after SHA. Absolute paths, drive letters, ADS, traversal, alternate separators, reserved names, duplicate/case-colliding names and symlinks are rejected.
* `Inputs`: strict CSV/NPY schemas, point identity, unique longitude-modulo coordinate permutation, fixed mask, orbit-linked historical rows, asset state/context/data identity. Producer origin strings are never opened.
* `evaluate_existing`: compatibility before reading case data, dual-domain point-count coverage, per-object interval union, pooled internal gaps, separate initial/final sensitivity, component reconstruction and full pointwise/endpoint comparison.
* `checker`: separate partition threshold, cumulative-maximum interval grouping, per-column Python component minimum and separate compatibility implementation. It rereads raw evidence and validates the emitted report; it does not call production threshold/union/gap/compatibility functions. Read schemas and byte tools are shared.
* `seal`: finalize status/report/logs, list bytes, independently read back files, then issue a one-way manifest receipt. Reentry checks the exact member set and semantic acceptance gates. Receipts are consistency records, not signatures or external attestations.

CSV empty first-hit cells mean no hit. Positive infinity is the NPY producer no-hit sentinel. NaN, negative infinity, negative time and values beyond the seven-day window are invalid. T90 uses integer `ceil(9*n/10)` and sorted hits; empty domains and unreached T100 remain null. The fixed provisional rule is `abs(geodetic latitude) <= 82.94340805970818`, excluding 354 of 43,424 points. Geometry/official permission is not re-certified.

Intervals are clipped and merged per target with 1e-6 seconds tolerance. Individual internal gaps are pooled across targets, including explicit zero/one-visit object records; per-target means are never averaged into the primary metric. Boundary gaps are separate. Component first hits and every merged interval endpoint are compared with whole results using a predeclared absolute time tolerance of 1e-6 seconds; hit/miss classification and counts are exact.
