# 第十六轮：完整保存 catalog 的 N28 单星替换

本轮在原 TEAM_COMPETITION_V3 物理协议、28 星基线及原可行约束下，
研究全部 2171 个保存资产。每次删除一颗基线星并加入一颗非基线星，
按删除索引、新增索引升序遍历 60004 个唯一组合。
donor 使用自己的原始保存高度（500 至 700km），允许条件性的混合高度。
这项离线研究不代表正式规则已接受混合高度。

入口：`D:\conda_envs\fmb\python.exe -X utf8 -B tools\run_round16.py`。
仅使用现有环境；不安装依赖、不访问原生 STK/COM、不写 Git。
已有 203 个消费文件保持原字节，使用独立 ROUND16_V1 profile。

在真实候选评价前冻结完整源码、测试、配置、文档、catalog 身份、
遍历次序、容差及证明条件。输入门逐一核验 2171 个 global NPZ、
4342 个 entry 及原始区域区间，将 NPZ 的全部 43424 个值与只读 mmap
矩阵相应行比较。原始浮点、生产者 float.hex 身份和各自高度的 SSO 关系保留。

从所有原始区域 payload 重建 Island_2 最长内部空窗及 bridge donor 集合。
预计 223 个 bridge 对应 6244 个完整精算；另 53760 个组合逐项核验证书，
只证明无法达到保守至少 1 秒 Tmax 改善，不推断其完整可行性。
内部零时长访问也算进入开空窗；端点相触不算进入。
单换没有 R15 双换的首窗例外。

主路径和独立 checker 对每个精算组合比较全部首访向量、三个对象的
合并区间、内部和边界空窗、可行门、改善门及排序。
T90 使用 ceil(9*n/10)，未全覆盖时 T100 为 null。
合并和数值绝对容差为 1e-6 秒，相对容差为零。
mask T90/T100 与池化内部 Tavg 不得劣于基线超过容差，
改善条件为 baseline_Tmax-candidate_Tmax-1e-6 >= 1。
合格者按 Tmax、Tavg、T100、T90、identity 排序。
首尾空窗和包含边界的指标独立列报，不加入主目标或可行门。

实际重跑旧 202 项、R14 的 89 项、R15 的 66 项回归，隔离消费源码
子集分别为 168、185、203 个文件；26 项历史绑定反例仍使用 142 文件。
新增 R16 测试单独计数，保存子集映射、命令、日志、返回码和前后摘要。

生命周期从首次准备起最多 7200 秒，科学和回归在 6600 秒截止。
父子进程共用剩余预算，保留实际完成前缀，FAIL 不被后续超时降级。
状态和报告先写，再生成精确成员清单和单向 receipt；
完整入口、Shell 及导出回执放在传输层，不回写封存内容。
